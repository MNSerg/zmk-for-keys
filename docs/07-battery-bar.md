# Индикатор заряда на клавишах (`&batt_bar`)

На слое **CFG**, средний ряд: зелёная шкала заряда **этой** половины (~2.5 с).

## Файлы

| Файл | Роль |
|------|------|
| `batt_bar.c` | поведение, карта LED |
| `corne,behavior-batt-bar.yaml` | binding |
| `led_strip_blank.c` | override: гасит все LED кроме шкалы |
| keymap | узел `batt_bar`, биндинги на CFG |

## Карта LED (средний ряд)

Индексы Corne/QMK (не подряд): `{25, 22, 19, 16, 11, 8}` → SW7–SW12.

Заливка: `floor(soc * 6 / 100)` (мин. 1 если soc > 0). ~49% → 2 из 6.

Во время показа underglow/RGB не перебивают шкалу (override).

## Настройка

- Длительность: `hold-ms` у узла `batt_bar` в keymap (сейчас 2500).
- Цвет/яркость зелёного: `batt_bar.c` → `.g = 90`.
- Другие клавиши: править массив `middle_row_leds[]` в `batt_bar.c`.
